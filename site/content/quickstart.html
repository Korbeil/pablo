Quickstart

From nothing to your first task in four commands. Each step links to its full page when you want the details.

Before you start

You need git, PHP 8.4 with Composer, OpenCode Claude Code or GitHub Copilot CLI, and the GitHub CLI gh, logged in with gh auth login. An agent environment, Orca or OpenChamber, is where you'll read the agents' work. Using Jira or Linear? See Prerequisites.

1. Install

curl -fsSL https://getpablo.dev/installer | bash

It asks where to install PABLO, which agent runtime and which agent environment to use among the ones it finds on your machine, then puts the pablo command on your PATH, starts the background scheduler and the dashboard, checks your tools, and prints what to do next. Open a new terminal if it tells you to. If a check fails, pablo system:setup walks you through each fix. More in Installation.

2. Add your project

cd ~/path/to/your/repository
pablo project:new

A short wizard: it detects the repository, asks for the issue tracker, and writes the project file. Agents use GLM 5.3 Flash through OpenCode Go by default, or Claude Sonnet when the installer set you up with Claude Code or Copilot; pick another model in ~/.pablo/config.yaml. More in Your first project.

3. Start a task

pablo task:start https://github.com/you/your-repo/issues/42
# no issue? describe it instead:
pablo task:start --project your-repo "fix callback verification"

PABLO creates a branch and a worktree, and the task-analyst agent starts reading the issue and the code to write an action plan.

4. Follow it

Open http://127.0.0.1:8321, or run pablo task:list. When the plan is ready, read it in Orca or OpenChamber, write the code, then run /pablo-commit-and-pr in OpenCode, Claude Code or Copilot to open the pull request. From there PABLO follows CI, reviews and QA, and launches the right agent when something needs you. The whole loop is in Your first task.
