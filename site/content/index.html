Documentation

Everything about installing, using and understanding PABLO, the orchestrator that watches your pull requests and launches the right AI agent, in the right worktree, when something needs doing.

1 Install PABLO One script, then a doctor that tells you what's missing. 2 Add a project Point PABLO at a repository and its issue tracker. 3 Start a task From an issue link to a merged PR, step by step.

In a hurry? The Quickstart fits all three on one page.

I want to…

  • start working on an issue or on an idea with no issue
  • open my pull request (/pablo-commit-and-pr)
  • see what needs me right now, in the terminal or in the browser
  • pause a task or force it into another state
  • adopt a branch I started without PABLO
  • choose which AI model the agents use
  • ignore a CI check that never finishes
  • understand how my branches are kept up to date
  • move PABLO to another machine
  • fix something that doesn't work
