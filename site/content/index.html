Documentation

PABLO watches your pull requests, CI and reviews, and launches the right AI agent, in the right worktree, when something needs you. You stop checking; you read the analysis that's already waiting.

⚡ Quickstart Install, add a project and start a task, all on one page.

I want to…

  • start working on an issue or on an idea with no issue
  • open my pull request (/pablo-commit-and-pr)
  • see what needs me right now, in the terminal or in the browser
  • pause a task or force it into another state
  • adopt a branch I started without PABLO
  • add or remove a project
  • choose which AI model the agents use
  • run the agents with Claude Code or Copilot CLI, or in another environment
  • ignore a CI check that never finishes
  • understand how my branches are kept up to date
  • update or uninstall PABLO
  • move PABLO to another machine
  • fix something that doesn't work

Is it for me?

PABLO fits if you use OpenCode, Claude Code or GitHub Copilot CLI experimental, work with GitHub pull requests (issues in GitHub, Jira or Linear experimental), run Linux or macOS, and juggle several tasks at once. It's a personal tool that runs on your machine: no server, no account, no telemetry.

What it never does

  • Write your code. Analysis agents are read-only by permission. The one exception, the rebase-conflict resolver, only resolves conflicts of a rebase that sync started, and can't comment, review or merge on GitHub.
  • Write a commit of its own. Your work is committed and opened as a pull request only when you run /pablo-commit-and-pr. With sync.auto_apply (off by default), it rebases your branch onto its target and pushes with --force-with-lease, never plain --force.
  • Change your issue tracker, or store tokens: it uses the CLIs you're already logged into.

The exact rules are in What PABLO may change. Press / anywhere on the site to search.
